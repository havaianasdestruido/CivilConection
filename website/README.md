# Documentação Civil Connection

Portal oficial construído com Docusaurus 3.10.2.

```bash
npm install
npm start       # desenvolvimento
npm run build   # validação e build estático
npm run serve   # serve o diretório build
```

Requer Node.js 20+. Conteúdo em `docs/`, navegação em `sidebars.js` e tema em `src/css/custom.css`.

A publicação padrão usa GitHub Pages em `/CivilConection/`. Para domínio raiz, defina `DOCS_URL=https://docs.exemplo.com` e `DOCS_BASE_URL=/` durante o build.
